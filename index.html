O que é HTML5?

HTML5 é a versão atual da linguagem utilizada para estruturar o conteúdo de uma página da web. Com ela, podemos inserir textos, imagens, links, listas e muitas outras informações.

HTML não é uma linguagem de programação. É uma linguagem de marcação, pois utiliza elementos para determinar o papel de cada conteúdo na página.

O que estudar para aprender HTML5?

Alguns dos tópicos importantes para estudar são:

  • A estrutura de um documento HTML5.
  • Como usar títulos, parágrafos, listas e links.
  • A diferença entre elementos semânticos e elementos genéricos.
  • Como adicionar imagens com texto alternativo.
