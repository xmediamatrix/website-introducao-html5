O que é HTML5

HTML5 é a versão atual da linguagem para estruturação do conteúdo de uma página da web. Podemos inserir textos, imagens, links, listas e muitas outras informações.

Ele não é uma linguagem de programação. É uma linguagem de marcação, pois emprega elementos para designar o papel de cada conteúdo.

O que estudar para se tornar importante

Alguns dos tópicos que pretendo abordar são:

  • A estrutura de um documento HTML5.
  • Como usar títulos, parágrafos, listas e links.
  • Elementos semânticos e elementos regulares.
  • Como adicionar imagens com texto alternativo.
