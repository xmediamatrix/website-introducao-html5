O Que é HTML5

HTML5 é a versão atual da linguagem para estruturação do conteúdo de uma página da web. Podemos inserir texto, imagens, links, listas e muitas informações.

Ele não é uma linguagem de programação. É uma linguagem de marcação, pois emprega elementos para designar o papel de cada conteúdo.

O que estudar para se tornar importante

Alguns dos tópicos que pretendo abordar são:

  • A estrutura de um documento HTML4.
  • Como usar títulos, parágrafos, listas e links.
  • Semánticos vs elementos regulares.
  • Como adicionar imagens con texto alternativo.
